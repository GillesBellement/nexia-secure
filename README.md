## 🎯 Présentation

**NEXIA** est une plateforme SaaS de cybersécurité IA souveraine, conçue pour protéger les entreprises contre les menaces numériques en temps réel — sans dépendance aux GAFAM.

> 🛡️ Données hébergées en France · IA locale · Aucune fuite vers des serveurs étrangers

---

## ⚙️ Fonctionnalités clés

| Fonctionnalité | Description |
|---|---|
| 🤖 **IA locale** | Mistral & Llama en local — zéro dépendance cloud |
| 🏢 **Multi-tenant** | Architecture isolée par client |
| ⚡ **Détection temps réel** | Analyse et alertes instantanées |
| 📊 **Dashboard analytics** | Visualisation des menaces en direct |
| 🔌 **API REST** | Intégration facile dans vos outils existants |
| 🔒 **Conformité RGPD** | Données souveraines, hébergées en France |
